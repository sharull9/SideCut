# Phases 085-090 verification

Verified on 2026-10-23 in Windows Chromium, on localhost development and compiled
production-preview builds. This batch is uncommitted.

## Reference and implementation

The baseline remains Tandem `735a9b8e162c1f951044baa892d94993869f2e77`.
`TakePairing.swift`, `SoundSync.swift`, `WordPlacement.swift`, and
`ThumbnailJob.swift` were inspected at that revision. Ports point to the bundled
Tandem MIT notice in `tests/fixtures/tandem/TANDEM-LICENSE`.

- Phase 085 adds `source-analysis.ts`, `derived-cache.ts`, the session's
  `media-analysis.ts`, and `source-samples.tsx`. Analysis stores 100 peak bins per
  source second and up to 60 small PNG thumbnails. Keys include a version and
  full source SHA-256. IndexedDB failures fall back to a 12-entry memory cache.
  Bin and timeline requests for one source share a job. IntersectionObserver
  defers offscreen analysis and image decoding. Drawing uses the visible slice,
  resizes without reanalysing, and reuses peaks and decoded thumbnails on scroll.
- Phase 086 adds lossless PNG frame-sequence proxies at up to 640 px wide. Every
  decoded frame keeps its original timestamp and duration, including variable
  durations and gaps. PNG retains decoded alpha without requiring another video
  encoder. The viewer checkbox selects the proxy for picture only. Sound readers,
  loudness analysis, and final export retain original files. Proxies persist as
  derived data; enabling them is a session preference. The shared CanvasSink now
  explicitly requests alpha, correcting its previous opaque default for both
  original rendering and proxy generation.
- Phase 087 adds portable filename/role pairing and version-1 Record It sidecar
  decoding. Identify takes pairs same-folder `<base>-camera` and `<base>-screen`
  video files case-insensitively. Duplicate roles and conflicting manual take
  IDs require correction instead of silently merging. Sidecar host timestamps
  produce offsets from the earliest source, with reference 30-second/duration
  checks. Existing role, take ID, and offset fields provide manual correction.
  Commands, undo, journaling, and project JSON preserve the result.
- Phase 088 adds coarse 2 kHz and fine 8 kHz band-limited GCC-PHAT alignment in
  a module worker, with the reference confidence threshold of 15 and fractional
  peak interpolation. Results are cached by the ordered pair of content hashes.
  The UI reports confidence/failure and commits take offsets atomically against
  the starting revision. Positive file-time offsets mean an earlier file start;
  negative take offsets shift the whole existing take so offsets remain usable.
  Existing timeline clips keep their placement. New offsets apply on subsequent
  synced placement, as explained in the UI.
- Phase 089 adds Transformers.js 4.3.1 and a local WASM transcription worker.
  The English `Xenova/whisper-tiny.en` q8 export is pinned at
  `79fb389fc764e7c395bd330e9531d9d32ada7049`. Its
  [model card](https://huggingface.co/Xenova/whisper-tiny.en) declares Apache-2.0.
  The explicit download/transcribe action discloses public model downloads from
  Hugging Face/CDN. PCM is transferred into the local worker, with no inference
  service or audio upload. Download/loading/inference states, job progress,
  cancellation, and cached word availability are visible. Cache keys include
  source content, model revision, language, precision, and analysis version.
  ONNX Runtime's browser WASM is bundled; its Node build scripts are disabled.
  Words after the real source end are discarded and crossing ends are clamped.
- Phase 090 adds the exported portable `placeWords` query and timeline word
  lanes. Shares are measured in source time, unioned before the half-word check,
  assigned to the largest share with earlier timeline clips winning ties, and
  clamped to the chosen clip. Repeated majority uses show again; repeated small
  fragments cannot manufacture a majority. Trims, speed changes, freezes,
  disabled clips, overlapping words, and zero-length word timestamps have tests.
  Word buttons seek through the existing editor view. Tracks expand to contain
  the word lane without overlapping the following track.

35 files. `vp run build` succeeds. Existing dependency directive warnings remain;
the browser speech worker is about 547 kB and its WASM asset about 26.9 MB before
compression. The Impeccable detector reported the existing track-header color
stripe; no new detector finding was introduced.

`tests/browser/source-analysis.js` supplies repeatable runtime probes. The
eight-second licensed Open Speech Repository fixture and its attribution remain
in `tests/fixtures/audio`. A generated 1280x720 VP9-alpha fixture contains eight

- Picture verification produced a 640x360, eight-frame PNG proxy. Seeks at 0,
  0.25, 0.9, 1, and 1.9 seconds matched original decoded timestamps and pixel
  values. The half-transparent region retained alpha 128; the transparent region
  allowed the source codec's alpha error of at most 2/255. Original export over
  blue decoded to `[1,0,255,255]` in the background and `[128,0,127,255]` in the
  red-over-blue region. The exported WebM was 2,108 bytes. See
  [picture measurements](phases-085-090-picture.json).
- Audio verification generated 800 peak bins. A 1,973-sample delay at 8 kHz was
  recovered as exactly 0.246625 seconds with confidence 236.809, within the
  acceptance tolerance of one 8 kHz sample, or 0.125 ms. Unit tests additionally
  cover reverse offsets, gain/polarity changes, silence, and unrelated sound.
- Real local transcription returned 16 words with usable source timestamps in
  approximately 4.7 seconds with model files already downloaded. See
  [speech measurements](phases-085-090-speech.json). This is a warm model-runtime
  measurement, not a first-download latency claim. A deliberately cancelled
  worker reached inference, rejected, and left no transcript cache entry.
- After browser reload, replacing `LocalMediaReader.open` with a throwing stub
  still retrieved the 800-bin waveform and 16-word transcript from persistent
  cache. Unit tests prove concurrent bin/timeline requests share one decode and
  a cancelled decoder finishing after project replacement cannot publish stale
  data into the new session.
- The compiled editor imported speech and the synthetic camera/screen pair.
  Identify takes persisted camera/screen roles, the shared `take:sidecut` ID,
  and zero offsets. Generating and enabling the camera proxy worked through the
  UI. Local transcription completed in the compiled worker and rendered 16 word
  buttons. Clicking `Glue` sought to 4.56 seconds. The transcript track measured
  90 px, adjacent tracks 44 px, with no page overflow or application alerts at
  1440x900. Thumbnails, waveforms, and the local-analysis form were visually
  inspected. The initial fixed-height-row overlap was reproduced and corrected.

## Limits and capability report

Only Windows Chromium is verified. Public hosting, other browsers, macOS/Linux,
native Tandem reopening, large-project throughput, and real mobile hardware are
unverified. Phase 028's public hosted-URL acceptance remains pending.

Analysis supports known-duration sources up to ten minutes and the existing
512 MiB source-hashing limit. Proxy generation supports video up to 60 seconds,
3,600 frames, and 128 MiB per proxy. PNG sequences trade storage for alpha and
codec independence; no H.264/ProRes proxy parity or throughput claim is made.
Derived disk entries are disposable and currently have no automatic eviction.

Browser file picking does not expose reliable recorder creation dates or scan
adjacent sidecars. Timing sidecars must be explicitly imported. Without them,
identification keeps known offsets or starts files together and reports the
limitation. Manual metadata is retained for unmatched files. Pairing is an
explicit action rather than a background folder scan.

Sound sync supports up to 60 seconds per source and one second of usable audio.
It ports the reference's core correlation method, not its long-recording
multi-stretch clock-drift fitting. Downsampling uses a packet-local box average;
room acoustics, long takes, clock drift, and unlike microphones need further
quality checks. Confidence measures correlation, not recording provenance.

Whisper Tiny differs from Apple's SpeechAnalyzer. On the fixture it transcribed
the opening as "The birch canoes lid" instead of "The birch canoe slid". Timing
is useful for navigation, not manually annotated ground truth. The initial
ONNX-community export lacked the cross-attention outputs needed for word times;
the selected Xenova export passes that runtime check. Its padded decoder also
invented words after the file ended, which are now excluded. In-source
hallucinations remain possible, especially for silence/noise. English only is
supported; no word error rate, diarization, or broad speech-quality claim is made.
Model downloads require network access initially; browser eviction can require
another download. Cancel terminates the worker, and cannot retain partial text.
Transcripts/proxies are local derived caches, not embedded in downloaded project
JSON. Search and pause refinement remain future phases. The next phase is 091.
