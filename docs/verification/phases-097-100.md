# Phases 097-100 verification

Verified on 2026-10-23 in Windows Chromium using the localhost development server
and compiled production preview. Changes remain uncommitted.

## Reference and implementation

The reference checkout remains Tandem `735a9b8e162c1f951044baa892d94993869f2e77`.
This batch ports marker and format editing from `Editing.swift`, `Model.swift`,
`Comments.swift`, `SectionCard.swift`, `SectionCardEditing.swift`, `Templates.swift`,
the built-in definitions in `LibraryDrops.swift`, `Layout.swift`, `LayerMath.swift`,
`Short.swift`, `SectionCardRenderer.swift` and `CardFonts.swift`.
Ports retain the notice in `tests/fixtures/tandem/TANDEM-LICENSE`.

- Phase 097 adds typed marker commands, nonnegative point/range times, stable
  IDs, unknown-kind preservation, review metadata round trips, comment trimming,
  deletion of emptied comments and one-line labels. Marker edits use the existing
  coordinator, merge patches, revisions, history and ripple rules. The timeline has
  marker and comment strips with section/chapter/todo colors. Click seeks;
  double-click or Shift+Enter edits. Previous/next navigation sorts imported markers
  by time. The dialog edits range, kind and note, and resolves comments by removing them.
- Phase 098 implements numbered section cards, placement before the marker so the
  wipe hides its cut, overwrite/place/insert modes, latest-first insertion, renumbering
  existing cards, fitted reading lengths, and linked sweep audio with the reference
  offsets and default -15 dB gain. Fitting moves the linked sweep-out sound. The Card
  inspector edits words, count, colors and cursor and can fit the duration. The browser
  compositor draws the skewed colored bands, title, subtitle, number, progress bars
  or proportional count, content rise and blinking cursor. Preview and export share it.
  Anton, Instrument Sans and JetBrains Mono are bundled through Fontsource under
  their SIL OFL licenses. Sounds use imported local media selected in the dialog.
- Phase 099 implements template substitution, relative clip times, track matching,
  fresh clip and link IDs, placement modes, carried media, transitions, effects,
  credits and template tags. Carried media IDs are remapped when a project, media,
  track, clip, transition or marker already uses the ID. The picker exposes the
  reference Section card, Like and subscribe and Comment below templates.
- Phase 100 implements per-format transforms, crop, hidden state and cutout override
  reading, `setFormatLayout`, and `adoptFormat`. Adoption rescales scale keyframes,
  offsets rotation keys, drops incompatible position/pan keys with a warning, clears
  overridden crop keys, disables hidden clips and removes the adopted alternate.
  `planShort` previews commands and warnings on a scratch coordinator and preserves
  the planned revision for application. The Formats dialog adds portrait/square
  canvases, previews them, places selected clips in full/top/bottom slots, hides or
  resets their overrides, adopts an alternate, and previews/applies a short layout.
  The viewer and export dialog select an output format using the same derived
  project view. Export format changes clear the previous downloadable result.

WebM named `Sections and formats portrait.webm`, measuring 1,710,725 bytes. Reading
the resulting Blob through an HTML video element confirmed those dimensions and

## Limits

Windows Chromium is the verified runtime. macOS/Linux, other browsers, public hosting
and reopening the resulting project in native Tandem remain unverified. There are
no captured macOS Tandem frames to establish pixel-level card parity. Canvas text
metrics, wrapping and edge antialiasing differ from Core Text. Bundled card fonts
cover Latin; other scripts use available fallback fonts.

The short proposal creates an alternate in this project. Filesystem copy/export
service envelopes and CLI/MCP operations remain assigned to the later service and
adapter phases. Portrait and square are the built-in UI format choices; imported
project formats remain selectable. Cutout overrides are preserved but enabled
cutout rendering still requires the later cutout phases. Sweep sounds are optional
local media; no licensed upstream sound recording is bundled.

The next phase is 101.
