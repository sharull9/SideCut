## Implemented

- 007: project validation reports severity, stable code, message, and affected
  object ID. It checks unique IDs, track kinds, clip ordering and strict overlaps,
  missing media, source bounds with Tandem's one-frame tolerance, image/hold/freeze
  exceptions, picture/audio compatibility, duplicate video effects, keyframe
  order, transition attachments, transition sounds, and singleton link warnings.
- 008: the synchronous coordinator applies all commands to immutable candidate
  values, validates, and then commits one revision. A failed batch changes
  neither the project nor history. Expected revisions reject stale callers, and
  idempotency keys return the original result without applying an edit twice.
- 009: `updateProject` changes only name/metadata through RFC 7396 merge patches.
  `updateSettings` supports partial settings patches, frame-rate warnings, speech
  level limits, and moving previously normalized audio clips except locked
  tracks. Subscribers receive one committed snapshot for a whole batch.
- 010: labelled and authored undo/redo restore entire immutable project values.
  Each undo/redo advances the revision, empty history is a no-op, and a new edit
  clears redo. Up to 500 undo entries are retained, matching the reference.
- 011: the starter is replaced by the top bar, media panel, viewer, inspector,
  eight standard empty tracks, timeline, and status bar. The existing shadcn
  theme, generated Button/Empty components, fonts, and Remix Icons are reused.
  Disabled playback/export controls and explicit empty states reflect the
  implemented functionality. The viewer preserves the canvas aspect ratio.
- 012: pointer and keyboard resizing for media, inspector, and viewer/timeline
  splits. Versioned local preferences preserve desired sizes through reloads.
  Viewer and timeline minimums remain available. Enter/double-click reset an
  individual split; Reset layout restores all defaults. Storage errors do not
  stop editing and appear in the status bar.

The React provider owns one coordinator per app instance. Editor and diagnostics
routes subscribe to that same session, using client navigation. There is no
second mutable UI copy of the project. Snapshots and commit results are deeply
frozen; caller-owned initial values are copied, including exact Time instances.
Observer failures cannot turn a completed commit into an apparent failure, and
reentrant observer edits reject until publication finishes.

## Limits

Project saving, multi-tab writers, external agent transport, and native process
coordination remain later phases. The coordinator serializes synchronous edits
within one JavaScript instance; it is not a cross-process or cross-tab lock.
The fixed initial empty session is temporary, not a saved project identity.

Only two of Tandem's 51 edit commands are implemented. Unknown commands reject
explicitly. Transition/effect/keyframe data is still preserved JSON; validation
checks the structural invariants described above, not full render-parameter
semantics. New clip/media operations will extend those schemas and tests.

Only Windows Chromium is verified. Mobile layouts, Firefox, Safari, macOS,
Linux, actual media import/playback, and native Tandem round trips remain
unverified. The first editable name/settings form is phase 013; the inspector
in this batch displays properties, while diagnostics exercises the commands.

The shadcn generator initially resolved its directory aliases outside the
workspace on this Windows setup. Its newly generated Empty file was moved into
`packages/ui/src/components` and its utility import aligned with the existing
shared helper. No generated file was left outside the workspace. Automatic
component-directory resolution remains a tooling limitation to fix separately.
