then crop/transform/opacity. Preview and WebM export call this shared painter.

Processing yields between groups of rows and observes export cancellation.

The Effects inspector has an explicit clip selector for linked picture/sound
selections. Existing shadcn fields, buttons, inputs, panel scrolling, and styles

## Limits

Only Windows Chromium was checked. Native Tandem reopening, macOS Core Image
pixel comparison, Firefox/WebKit, other desktop platforms, real touch hardware,
and a complete accessibility audit remain unverified. Phase 028's public hosted
acceptance is still pending. No deployment was made.

CPU processing is intended for correctness at this stage. Large source images,
long stacks, and long exports can be slow and consume substantial memory. Source
canvas pixels are RGBA8; HDR/color-profile fidelity and GPU acceleration remain
later work. The numeric wheels save on Apply parameters, rather than providing
continuous sequence preview while dragging.

LUTs are browser-local assets. Downloaded project files retain paths but contain
no LUT or media bytes. Re-import a LUT on each device. The browser accepts files
up to 32 MB, 3D dimensions 2-128, and 1D tables with 2-1,000,000 entries. Combined
1D/3D tables and invalid domains are rejected explicitly. This is stricter than
some malformed-input behavior in the reference.

Sharpen, blur, pixelate, borders, shadows, rounded corners, audio effects,
transitions, titles, graphics, and mixing remain later phases. Disabled pending
effects remain editable. Existing journal/storage, source-edge, five-minute,
1080p, 1-60 fps, and codec limits remain. Interactive undo history resets on reload.
