Verified on 2026-10-23 in Windows Chromium. Phases 073-078 are committed as

## Implementation and reference

The baseline remains Tandem `735a9b8e162c1f951044baa892d94993869f2e77`.
The local reference's `AudioEffects.swift`, `RenderPlan.swift`,
`CompositionAssembler.swift`, and `TransitionSounds.swift` were inspected.
The checked cleanup and sound-lifecycle reference files have no diff from the
pinned commit. Ports retain the notice pointing to the bundled Tandem license.

- Phase 079 adds the reference high-pass biquad and linked downward expander,
  including high-pass frequency, threshold, and range controls in Effects.
  Cleanup runs at the normalized base gain. Unsupported effects still fail
  preflight rather than silently disappearing.
- Phase 080 adds a separate 0-1 isolation blend using Jitsi RNNoise WASM 0.2.1
  in a local module worker. The worker applies an 80 Hz rumble filter before
  RNNoise, flushes its tail, and compensates its measured 960-sample latency.
  Each channel has independent model state. No audio is uploaded. The original
  and isolated branches receive their own dynamics before blending, as in the
  reference. A regression covers cleanup, base gain, and normalization together.
  Missing Worker/WASM support and worker loading errors produce actionable
  messages. Aborting terminates the worker and rejects its result.
- Phase 081 extends audio segments through cut-centered transition handles,
  applies sine equal-power envelopes, and leaves unavailable source handles
  silent. Explicit clip fades still apply. Tests check a 0.25-amplitude pair
  at the cut against `0.25 * sqrt(2)`, with adjacent-sample jumps below 0.0001.
- Phase 082 creates ordinary SFX clips, keeps `soundClipID` ties, and reconciles
  sounds after each command through the existing coordinator. Roll and ripple
  preserve midpoint offsets. Replacement, detach, deletion, explicit sound
  edits, negative-start trimming, track allocation, locks, undo, and journal
  replay have coverage. Removing a transition retains sound on a locked track
  with a warning.
- Phase 083 adds transition source, gain, offset, tie/detach, attribution, and
  per-type preferences. Preferences are scoped to the project because local
  media IDs belong to that project. Push/slide/cutSlide/wipe identify the
  reference light swoosh as unavailable, retaining its asset ID, -23.3 dB gain,
  and -0.39 s offset. Its licensed media is not bundled. Imported local audio
  can replace it and become the remembered default. Actual scheduled stereo
  PCM supplies peak/RMS meters and clipping warnings, updated at most 10 Hz.
- Phase 084 adds session-owned Effect jobs with non-preemptive priorities,
  bounded concurrency, progress, and cancellation. Preview preparation has
  priority 0, export 10, and source analysis 20. Closing/replacing a project
  aborts its jobs. Workers terminate, analysis closes decoder iterators, and
  export cancels its encoder and closes readers. Cancelled results cannot
  publish as successful jobs.

## Checks and runtime evidence

`vp run check` passes formatting, lint, TypeScript, and 198 tests across 29
files. `vp run build` succeeds. Build output includes a self-contained worker
of approximately 2.01 MB. Existing dependency directive warnings remain.

The speech fixture is eight seconds of Open Speech Repository test speech,
resampled to 48 kHz, placed between one-second quiet sections. The fixture
README records its source, permitted use, derivation, and hash. The harness
adds deterministic 40 Hz rumble and low-amplitude random noise.

`tests/browser/advanced-sound.js` exposes `verifyVoice()` and
`verifyExportJobs()` for Vite `/@fs/` imports. Speech acceptance requires more
than 10 dB quiet-section noise reduction, cleanup correlation above 0.8,
isolation correlation above 0.65, unchanged frame count, blend error below
0.000001, and decoded export correlation above 0.9. Correlation is a waveform
preservation proxy, not a listening or speech-intelligibility study.

The recorded ten-second fixture measured 17.40 dB noise reduction and 0.8831
speech correlation for cleanup, and 18.12 dB and 0.8200 for isolation. Cleanup
took 27 ms and isolation 646 ms on this machine. Isolation retained 480,000
frames. Dry/half/wet blend error was 1.49e-8. Native Opus exports at mixes 0,
0.5, and 1 had correlations 0.99921, 0.99960, and 0.99976 against expected PCM,
with no best-fit codec offset. See the audio JSON alongside this report.

This check exposed one-sample gaps at decoded packet boundaries in the dry
stream. Decoder timestamps rounded slightly above the sample clock, so the
mixer skipped samples. A timestamp-tolerance regression failed before the fix
and passes afterward. Another regression failed when cleanup ran after blending
and passes with independent dry/wet processing.

Cancelling an actual WebM export after encoding began rejected the job without
publishing its old result. Restarting the same ID produced a 17,653-byte WebM;
job history reported cancelled then done. Worker cancellation also rejected,
and a fresh worker returned the expected 4,800 samples. Queue tests cover
priority, concurrency, queued cancellation, failures, and stale results.

Through the running editor, a speech-and-solid project attached a sound at
cut midpoint minus 0.25 s with -18 dB gain. Detach retained the ordinary SFX;
reusing its saved default created another tied clip on SFX 2 because the first
track was occupied. Reload retained both clips and the per-type preference.
Playback displayed preparation progress and actual mix readings, including
12.6 dBFS peak with the clipping warning after deliberately applying +30 dB
gain. No playback alerts occurred. The inspector was visually checked at
1440x900. Long inspector content uses its existing scroll container.

The compiled app was served locally for native worker verification. Importing
the speech WAV, placing it through the bin, applying 0.5 isolation, and playing
the sequence completed without alerts. No deployment was made.

## Limits

Only Windows Chromium is claimed. Other browsers, operating systems, real
touch devices, native Tandem reopening, and listening comparisons remain
unverified. Public-host acceptance for phase 028 is still pending.

RNNoise suppresses noise; it does not reliably separate speakers or remove
music. The recorded noise reduction includes its high-pass preprocessing.
The fixture and timings do not establish quality across real recordings or
equivalence to Apple's voice isolation. Isolation starts at each processed
clip/handle span, so model warm-up and effect state may differ from Tandem's
whole-source caches. Existing granular pitch/speed limits remain.

Cleanup, dynamics, and mixing yield on the browser thread. Isolation runs in
workers. Processed clips use full float buffers; intermediate isolation mixes
process both branches and consume extra memory. Existing five-minute clip,
ten-minute source/combined-preview limits and export limits still apply.
Cancellation is checked at processing/decoder yields; it is not a hard real-time
deadline. No large-project throughput claim is made. Meters describe the preview
mix before export's master loudness/true-peak stage.

Preferences do not travel with exported project JSON. The reference swoosh
requires an imported licensed replacement. Media relinking, pan processing,
waveform/thumbnail generation, and later analysis phases remain pending. The
next phase is 085.
