# Phases 111-115 verification

Verified on 2026-10-24 on Windows with Electron 45.0.0 and Chromium. Changes are
uncommitted. The next implementation phase is 116.

## Implementation

- Phase 111 retains the shared production editor at `sidecut://app`, with
  sandboxing, context isolation, disabled renderer Node integration and navigation
  restrictions. The preload exposes named operations rather than raw IPC, paths,
  executables or arbitrary filesystem access. New native handlers validate the
  main frame's sender, operation and input limits. Browser code imports only
  portable contracts and its renderer adapter. The desktop TypeScript program
  uses bundler resolution because `vp pack` bundles the shared source packages.
- Phase 112 adds `HostProjectService` around the existing core coordinator.
  Windows receive encoded project snapshots, save status, revisions and shared
  undo/redo labels. In-memory edits use synchronous typed IPC to preserve existing
  command result semantics; disk and media operations remain asynchronous.
  Project identity and generation checks reject requests from a replaced project.
  Renderer replacement cancels work started against the previous project. Closing
  a renderer detaches its subscriptions without replacing the host authority.
- Phase 113 adds `NativeProjectStore`. Saves validate the journal, write and flush
  a unique temporary file, preserve a validated backup and rename the replacement.
  Exclusive lock files prevent cooperating hosts from competing. Exact-content
  checks detect external modifications before saving. Errors expose download,
  disk reload and backup recovery choices. Normal application quit flushes the
  save queue and releases the lock.
- Phase 114 adds recursive folder scans and a portable polling watcher. It applies
  the pinned Tandem folder exclusions and role precedence, including record-it
  suffixes, nearest named folder and short audio fallback. Filmora `.wfp.dir`
  folders, hidden files/folders and symlinks are excluded. Files must retain size
  and timestamps for two seconds before being reported. Changes update the
  existing media ID. FFprobe supplies native metadata, with WAV decoding available
  for audio the browser cannot decode.
- Phase 115 adds host-only FFprobe/FFmpeg jobs behind the resource/export path.
  Jobs use fixed arguments without a shell, allowlisted formats and local
  protocols, progress events, cancellation and a five-minute execution timeout.
  Window destruction or application quit cancels owned jobs. Cancellation waits
  for child close before temporary files are removed. Timeline composition stays
  shared with the browser, followed by native VP8/Opus WebM encoding.

The scanner rules derive from `TandemMedia/MediaScanner.swift` and the settling
behavior from `FolderWatcher.swift` at reference revision
`735a9b8e162c1f951044baa892d94993869f2e77`. The retained upstream notice is
`tests/fixtures/tandem/TANDEM-LICENSE`. SideCut also accepts its existing additional
browser media extensions.

## Checks

`vp run check` passes formatting, lint, all TypeScript programs and 301 tests in
60 files. Eleven new tests cover shared authority, stale revisions/generations,
reopening, lock contention, malformed requests, external edits, backup recovery,
interrupted temporary writes, role/exclusion rules, file settling, duplicate
suppression, native media errors, real codec execution and child cancellation.
The real-codec test runs against the desktop dependencies. No tests skipped here.

`vp run build:desktop` passes for both the production editor and host/preload
bundles. Existing dependency directive, route-generator circular dependency and
CommonJS preload recommendations remain warnings. Electron also reports an
existing safeStorage synchronous API deprecation from credential initialization.

`tests/desktop/verify.mjs` runs against the production build using a temporary
profile and synthetic speech. Its [runtime results](phases-111-115-runtime.json)
confirm:

- Renderer `process` and `require` are undefined; only named bridge functions are
  exposed. The built editor loads successfully.
- Two windows share revision 1 after one rename. Stale undo is rejected. Undo and
  redo persist revision 3, and a reopened window reads that revision.
- A selected folder imports one WAV under `music/fixture.wav`, excludes the
  `exports` copy and retains the same media ID after the source changes.
- Placing and trimming that source in the timeline exports a 3,377-byte
  VP8/Opus WebM. Its container duration is 0.228 seconds for a 0.2-second timeline,
  including codec/container padding. A direct native trim exports a 2,336-byte
  Opus WebM with a 0.208-second container duration.
- The production UI reports `Saved on this device`.

The collaborative browser at `http://localhost:4270/` also imports a new project,
shows `Saved in browser`, exposes no desktop bridge or `require`, and reports no
alert. The browser production build succeeds independently of Electron.

## FFmpeg dependency follow-up

Added `ffmpeg-static@5.3.0` and `ffprobe-static@3.1.0` as desktop runtime
dependencies. `pnpm-workspace.yaml` permits the FFmpeg installer to download its
binary. Host resolution uses installed absolute paths, with existing
`SIDECUT_FFMPEG`/`SIDECUT_FFPROBE` overrides preserved. The pack configuration keeps
both packages external so module-relative binary locations survive bundling.

The complete production Electron verification passed again with FFmpeg and
FFprobe removed from PATH, including folder metadata probing, stable source
refresh and timeline VP8/Opus export. The runtime JSON reflects this run. Binary
resolution tests also check installed files and explicit overrides.

Package provenance: [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static)
and [ffprobe-static](https://github.com/derhuerst/ffprobe-static). Installed package
and downloaded binary licence companions remain alongside the binaries. No
installer/distributable has been produced or verified.

## Limits

Runtime verification covers Windows only. macOS, Linux, packaged installers,
signing and additional codecs remain unverified or later phases.

Native projects currently use the managed profile's `current.tandem`; choosing
arbitrary project folders and portable archives are later work. Imported media
copies remain in the renderer's IndexedDB. Folder selection is session-local and
must be repeated after application restart. Reselecting also retries failed
imports. Removed sources are retained as references rather than deleting clips.

Folder imports and native inputs/outputs are limited to 256 MiB, 10,000 files and
32 directory levels. Native decode/export requires a known duration up to five
minutes. FFmpeg and FFprobe are installed as pinned desktop runtime dependencies;
no system installation is required. Host environment variables can override
the executable paths. The shared compositor retains browser decode, canvas-size and rendering
limits; native re-encoding does not establish a separate native compositor or
pixel-identical output.

Locks coordinate SideCut hosts. External programs need not honor them. A crashed
host can leave a lock file, which requires manual removal after confirming no host
is running. Interruption tests simulate a partial temporary write and reopen the
last valid file; they do not establish power-loss durability on every filesystem.
