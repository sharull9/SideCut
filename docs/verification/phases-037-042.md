## Implemented behavior

- 037: `join` and `joinThroughEdits` preserve the left clip's identity and merge
  tags, outer fades, transitions, and compatible keyframes. Effects compare by
  settings rather than ID; merged effect keyframes use the retained IDs. A join
  rejects playback discontinuity, a fade/transition at the cut, incompatible
  animation/settings, locked tracks, or unmatched linked partners. Each linked
  cut joins atomically. Scans include range boundaries and report skipped cuts
  once per take, with the earliest three reasons and a count of further skips.
- 038: `setSpeed` accepts finite values above zero through 100, preserves the
  source duration, scales keyframe times, and supports linked and independent
  edits. Ripple moves following clips and propagates the primary duration delta
  through the existing cut/follow/off and marker rules. Overlaps, locked partners,
  freeze primaries, and zero-duration results reject atomically.
- 039: `holdFrame` cuts only the requested picture, freezes the frame one project
  frame before the requested range, and keeps all pieces in the original link
  group. Sound continues uncut. `holdEdges` allows a source range beyond file
  bounds; preview and export clamp picture to the source edges and omit sound
  outside the actual source interval. Frozen audio is silent and does not create
  an empty encoded audio track.
- 040: `updateClip` applies recursive JSON merge patches. Omitted fields remain;
  null removes a field, allowing optional fields to clear and defaulted fields
  to reset. IDs cannot change. Known video/audio properties, content, timing,
  references, source bounds, and overlaps validate before a batch commits.
  Unsupported rendering data still round-trips for later phases.
- 041: `placeMedia` routes roles to the reference tracks, creates tracks when
  needed, derives available duration/source starts, aligns take offsets, and
  links picture/sound. It supports place, overwrite, and a single ripple insert
  for the whole plan. Camera/other sound and audio cut tracks receive speech
  defaults; music/SFX defaults follow the reference. Sticker anchor/pop data is
  generated without claiming its rendering support. A plan that puts two files
  on the same track rejects instead of silently overwriting one planned clip.
- 042: `placeSynced` uses existing take identity and source offsets. It chooses
  the reference camera/picture/sound track, rounds partial coverage inward to
  whole frames, skips sub-frame coverage and partial spans below 0.5 seconds,
  and cuts linked take members at coverage boundaries. Pictures go disabled on
  a new Angle track above camera; external sound replaces the take's own sound,
  which moves to a muted Camera sound track. Missing sync/reference data,
  duplicate placement, incompatible/occupied destinations, and locked linked
  members reject atomically. Non-unit-speed/frozen references produce warnings
  and are skipped. Ripple cuts retain source-offset relationships.

The schemas live in `packages/contracts/src/commands.ts`. Core implementations
are in `through-edits.ts`, `media-placement.ts`, `timeline-editing.ts`, and the
existing coordinator/validator. Preview and export share picture/audio source
mapping in `render-plan.ts`. The inspector adds clip properties, speed/ripple,
held ranges, and Join next clip. The toolbar adds Join through-edits. Each bin
source has expandable role/take metadata and default/synced placement controls.
These use the same coordinator, revisions, idempotency, save queue, and undo/redo.

## Remaining limits

Windows Chromium is the only verified runtime. Other browsers/platforms,
native Tandem reopening, and public-host acceptance remain unverified. Phase
028's public-host check is still open. No deployment was created.

Picture speed changes, held ranges, and held edges render through the current
single-picture/single-sound pipeline. Audio speed changes require the later
pitch-correction pipeline; speech normalization requires later loudness analysis.
Those settings remain explicit preview/export preflight errors. Muting such
audio allows the supported picture export. Placement preserves reference audio
defaults instead of pretending to render them. Sticker transforms/pop, general
effects/compositing, and enabled multiple angles likewise need later renderers.
Automatic sync by sound is not part of `placeSynced`; the bin accepts known take
IDs and offsets. Angle range switching remains phase 043.

Join warning text explains the reference conditions but is not verbatim upstream
text. Unknown/custom effect parameters without a known static default can
conservatively refuse one-sided animated joins. Transition-bound sound editing
retains the prior explicit rejection where timeline helpers do not support it.
Undo history still resets on reload. Existing five-minute, 1-60 fps, 1080p, codec,
memory, and basic-processing export limits remain. These checks do not establish
full Tandem compatibility.
