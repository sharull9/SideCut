# Agent notes

## ui-sdk

`@ui-sdk/react` and `@ui-sdk/core` are dependencies of `apps/web`, so the docs live under `apps/web/node_modules/@ui-sdk/react/docs/`.

- Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read `apps/web/node_modules/@ui-sdk/react/docs/llms.txt`.
- To build a new component, also search `apps/web/node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` in the same folder.
