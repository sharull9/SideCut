## Checks

`vp run check` passes formatting, lint, all TypeScript programs and 290 tests in
56 files. `vp run build:desktop` builds both the production web editor and desktop
main/preload bundles. Existing dependency directive, route-generator circular
dependency and CommonJS preload recommendations remain build warnings.

Each adapter has a separate test file, except shared library coverage in
`packages/assets/src/provider.test.ts`. Those tests cover one successful mapping
and a relevant setup, invalid response, missing file, permission or fallback
case. Credential tests use mocked Electron encryption; they verify encrypted
bytes, removal, unavailable encryption and rejected provider names.

The browser probes in `tests/browser/assets-segments.js` passed again through T3
collaborative browser evaluation at `http://localhost:3005/`. The recorded
[runtime results](phases-106-110-runtime.json) include the earlier successful run.

- Provider checks normalize a credited Iconify SVG to a 293-byte PNG, retain its

  import a shared folder asset and stop cancelled work. Twelve provider states
  distinguish browser restrictions, disabled Freesound and upstream stubs.
- Mock generation stores a generated audio asset after one request.
- A saved segment inserts three linked picture/audio clips, two media resources
  and one transition into another project at revision 1. Its media renders and

  names and overlapping insertion are rejected. Undo and redo restore the
  insertion as a whole.

## Limits

Live keyed requests, paid generation, installed Electron credential storage and
other browsers/platforms remain unverified. Mock fixtures establish the pinned
contracts, without proving current remote service availability or account rights.
Phase 109's live acceptance remains open. No secret or paid request is needed for
ordinary checks.

Asset and segment catalogues are local to a browser origin or desktop profile.
Saved segment resources are limited to 256 MiB. Missing required resources stop
saving/insertion; absent optional licence companions are omitted while embedded
credit metadata remains. Browser storage removal deletes the local binaries.
Project JSON preserves references and provenance without embedding those files.
