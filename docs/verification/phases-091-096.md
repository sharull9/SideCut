  boundaries, and the `search` result shape: timeline hits grouped by clip range with
  `partial` when a cut runs through the phrase, plus `unused` matches in removed or unplaced
  source material and `missing` transcripts. Search places words on every track, including

  same `searchSpeech` query; clicking a hit seeks and selects its clips.

## Limits and capability report

Only Windows Chromium is verified. Other browsers, macOS/Linux, native Tandem reopening,
large-project throughput and public hosting remain unverified.

Phase 095's acceptance names saved reference frames from Tandem. No macOS Tandem renders
were available, so frame comparison against Tandem is pending. Canvas text differs from
Core Text: line breaking is greedy at spaces, metrics use CSS font bounding boxes, runs are
measured separately (kerning across colour changes can shift by a pixel), and shadow blur
is approximate. The system font is the browser's `system-ui`, not SF Pro, so default titles
are a different typeface on Windows.

Browser font detection compares fallback metrics; a local font with identical metrics to
all three generic fallbacks would read as missing. WOFF/WOFF2 imports take their family from
the file name. Imported fonts are stored per device and are not embedded in downloaded
project JSON. Other preset fonts are not downloaded on demand.

Alignment quality depends on the waveform. On the noisy 8 kHz-derived fixture the voice
threshold (10 dB over a -41 dB floor) leaves 2.87-3.75 s below threshold, so "planks." was
pinned to a 40 ms blip at 3.75 s, as the reference algorithm does with the same peaks.
Pause and caption timing near quiet speech inherits this. Transcription limits from phase
089 still apply.

Plans are previewed on a full scratch copy of the project, which is fine for current
browser project sizes but not tuned for very long timelines. The `mike` request field is
supported in the core request; the UI exposes its values as editable defaults. Service,
CLI and MCP transport for `search`, `pauses`, `tighten` and `captions` remain phases
119-131. The next phase is 097.
