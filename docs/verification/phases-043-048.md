## Implemented behavior

- 043: `showAngle` rounds the range edges to project frames, requires one synced
  take, and switches the take's angle tracks above its camera. The camera stays
  underneath and fills uncovered parts. Other takes and sound enabled states do
  not change. Range edges use the existing linked blade operation, preserving
  source offsets and link groups. Locked angle tracks reject atomically; locked
  linked sound follows the reference blade behavior, warning and remaining uncut.
  The inspector has an explicit Angle track selector and range controls. Selecting
  the camera disables the alternate angles in that range.
- 044: The coordinator records revisioned command batches, deterministic entry IDs,
  author/result data, and a base snapshot. Generated clip/track/link IDs replay
  from the same project/revision/idempotency seed. Undo and redo add full snapshot
  entries. `replayJournal` rebuilds and validates the journal against its snapshot;
  gaps, duplicated revisions, mismatched results, and mismatched snapshots fail.
  Retry keys and their original results survive session reopening. Exported journal
  data is immutable. The interactive undo stack still resets on reload.
- 045: IndexedDB version 2 retains existing projects/resources and adds journal
  staging and previous-version stores. A save validates replay, stages the next
  envelope, then atomically writes the snapshot/backup and clears staging. A failed
  stage leaves the snapshot untouched. A failed snapshot transaction leaves a
  recoverable staged journal. Load rejects incomplete staging, repairs from valid
  staging or the previous version, and reports recovery in Edit notes. Exact stored
  version comparisons reject stale writers before replacement. Save failures leave
  the in-memory edit available for download or retry.
- 046: Schema 1 upgrades to schema 2 with the pinned legacy text rules: values equal
  to the old style defaults become absent, explicit overrides remain, and the old
  0.4-second animation default becomes absent. Schema 2 is not upgraded again.
  Missing versions retain the reference current-version default. Unsupported
  schemas/content open read-only with an original-JSON inspector. They do not
  replace the saved project, cannot enable editing, and download their original
  file text byte for byte, including numbers outside JavaScript's safe integer
  range. Supported project/envelope fields continue to round-trip.
- 047: Portable `framePlan` in core selects picture layers bottom to top and maps
  source time through cuts, speed, holds, track visibility/solo, and clip enabled
  state. Clip intervals are half-open. Both preview and export consume this plan
  through one shared browser painter. Existing audio/source-range helpers remain
  shared; audio mixing is still a later phase.
- 048: The shared painter composites video, image, and solid layers over black.
  Geometry fits source dimensions inside the canvas, applies uniform scale,
  normalized position, and clockwise rotation about the center. A negative uniform
  scale becomes a half turn; zero scale draws no area. Preview uses a reusable
  staging canvas so superseded asynchronous decodes cannot paint stale frames.
  Multiple picture tracks no longer fail export preflight. Unsupported processing
  still fails explicitly.

The browser journal is a SideCut envelope extension, `sidecutJournal`, rather than
Tandem's native JSON-lines journal file. It preserves the command model and replay
behavior without requiring filesystem append access. Project downloads include the
journal and media references; media bytes remain local IndexedDB resources.

## Remaining limits

Only Windows Chromium was exercised. macOS/Linux, Firefox/WebKit, native Tandem
reopening, accessibility auditing, and touch interaction remain unverified. Phase
028's public hosted-URL acceptance is still pending; no deployment was created.

Journal retention is currently unbounded and replay verifies the full retained
history, so very long editing sessions increase save/load cost and download size.
The existing 20 MB project-import limit still applies. There is one previous
snapshot, not a version browser. Undo/redo entries preserve results for recovery,
but the interactive undo stack is not reconstructed after reopening. Browser
storage eviction can remove snapshots, journal, backups, and media together;
downloaded backups remain necessary.

Schema 1 text migration preserves data, but title rendering remains phase 094.
Future-schema imports offer JSON inspection and exact downloading, not editable
or rendered previews. Known-schema unknown fields continue to round-trip.

Crop, nonneutral opacity, keyframes, effects, transitions, titles, graphics,
cutouts, and alternate-format overrides need later renderers. Source alpha uses
canvas compositing, but codec/alpha support is still platform dependent. Audio
speed and speech levelling remain explicit preflight failures, and multiple audio
tracks still require a later mixer. Existing five-minute, 1-60 fps, 1080p, codec,
and memory export limits remain. These checks do not establish full Tandem parity.
