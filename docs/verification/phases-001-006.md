# Phases 001-006 verification

Verified on Windows on 2026-10-21 against pinned Tandem revision
`735a9b8e162c1f951044baa892d94993869f2e77`.

## Implemented

- 001: synthetic empty and miniature `.tandem` envelope fixtures in
  `tests/fixtures/tandem`, with expected defaults, IDs, track order, duration,
  provenance, and the upstream MIT notice. No private media is included.
- 002: signed 64-bit range checked `bigint` flick arithmetic, 48 kHz sample
  snapping, Swift-compatible negative half rounding, rational frame calculations,
  and six-decimal JSON seconds. Unsafe or unrepresentable time input rejects.
- 003: `/diagnostics` performs real WebCodecs encode/decode and a real-time
  synthetic audio/video recording with browser container/video/audio decoding.
- 004: Effect schemas for the actual `{ revision, project }` envelope, project
  identity, settings, metadata, reference defaults, and version rejection.
- 005: tracks, ripple modes, media roles, source paths, source flags, fingerprints,
  take IDs/offsets, and stable IDs survive serialization.
- 006: clip/source timing, links, speed, flags, tags, and all five implemented
  content variants survive serialization. Unknown content tags reject. Other
  valid JSON fields, including nested style, effects, markers, transitions, and
  graphic props, are preserved without claiming their editing/rendering support.

## Checks

`vp run check` passes formatting, lint, all workspace TypeScript programs, and
10 tests covering defaults, invalid inputs, future versions, content variants,
nested field preservation, exact timing, and repeated round trips.
`vp run build` passes SPA client/server compilation and shell prerendering.

## Browser evidence

Used the running app at `http://localhost:3001/diagnostics` because port 3000 was
already occupied. Clicked both checks in headless Chromium 155 on Windows.

- Schema checks passed in the browser with revision 7, project `prj_mini`,
  schema 2, three media references, five video and three audio tracks, all five
  content variants, a stable round trip, and rejected future version 99.
- VP8, VP9, and H.264 each encoded and decoded three 64x64 frames.
- The synthetic recording produced 8,330 bytes of WebM with 64x64 VP8 video and
  stereo 48 kHz Opus audio. Browser audio decoding returned 43,200 frames with
  RMS 0.10559, above the probe's non-silence threshold. Independent `ffprobe`
  inspection of the blob confirmed both codecs, dimensions, rate, and channels.
- Disabling VideoEncoder and MediaRecorder in the test browser produced explicit
  unavailable results, no download link, and a re-enabled run button. This is a
  simulated missing-API check, not evidence for another browser.

Raw results are in [the Chromium report](phases-001-006-chromium.json) and
[the simulated unsupported report](phases-001-006-unsupported.json).

The T3 preview opened the URL, but snapshot inspection twice failed with
`Preview automation snapshot timed out after 15000ms.` Verification therefore
used the installed `agent-browser` through `vp exec` with an isolated named
session. Its automated blob-download command reported `Download was canceled`;
the blob remained fetchable and its bytes were inspected independently. Browser
download-manager behavior is not established by this check.

## Limits and next phase

Only Windows Chromium is verified. Firefox, Safari/WebKit, macOS, and Linux are
unverified. This probe demonstrates one real-time synthetic browser output path,
not offline timeline export, arbitrary media import, AAC encoding, 4K throughput,
alpha, or codec support across machines. No media dependency has been selected
from support flags alone.

The schema implements structural decoding for version 2. Schema version 1 rejects
until phase 046 adds migrations. Cross-reference/timeline validation is phase 007;
rendering and edit commands are later work. Nested properties for those later
features are preserved as JSON rather than normalized into complete typed models.
The fixtures follow the Swift source contract but have not been opened in the
native Tandem application on macOS.

The diagnostics route is a development verification page, not the phase 011
editor interface. A reload clears probe results; committed reports are dated
evidence, not live capability claims.
