# Phases 101–105 verification

Verified on 2026-10-23–24 in Windows Chromium, using localhost development and compiled
production previews. Changes remain uncommitted. The next phase is 106.

## Implementation and reference

The pinned reference remains Tandem `735a9b8e162c1f951044baa892d94993869f2e77`.
The relevant files are `Model.swift` Cutout/Mask, `FrameComposer.swift` cutout and
repair-shape order, `MatteJob.swift`, `TandemAssets/Model/Asset.swift`,
`AssetNormaliser.swift` and `LottieRenderer.swift`. The reference notice remains in
`tests/fixtures/tandem/TANDEM-LICENSE`.

- Phase 101 uses MediaPipe Tasks Vision 0.10.32 and the Apache-2.0 Selfie Multiclass
  256 × 256 model, version 1. Hair, skin and clothing form the person matte;
  accessory confidence joins them in person-and-props mode. Inference runs locally
  in a CPU WASM worker. Its runtime files are bundled; first analysis downloads the
  public model. The cache uses full source-content hashes, model/version keys and
  exact decoded frame timestamps. PNGs hold the two confidence channels. Only a
  complete analysis publishes its manifest. Jobs expose progress and cancellation.
  Missing analysis and uncovered timestamps produce actionable rendering errors.
- Phase 102 applies source-coordinate include/exclude rectangle, rounded rectangle
  and ellipse repairs, then choke, then edge feather before crop and transform.
  Include takes maximum alpha; exclude multiplies by inverse shape alpha.
  Sizes are pixels at 1080p. The Picture inspector edits these settings through the
  existing coordinator and supports undo and persistence. The same compositor runs
  in preview and export. Download cutout PNG exports repaired source alpha.
- Phase 103 adds an IndexedDB asset catalogue with provider/providerID identity,
  kind, name, tags, licence class, credit line, normalized relative paths and
  preserved extension metadata. Original, normalized and licence files are stored
  atomically with the catalogue entry. The local library exposes search, kind and
  licence filters, details, a first-frame preview and missing-file status. Project
  media retains the asset metadata when used and saved/reopened.
- Phase 104 rasterizes self-contained SVG and browser-decodable still images to
  PNG with a maximum 2048 px long side, validates .cube LUTs with the existing
  parser, and validates/registers fonts through FontFace and the existing font
  loader. Font imports require a retained licence companion. Invalid formats,
  SVG scripts/external resources, absent font licences and invalid LUTs fail
  without publishing a library entry. Duplicate local imports do not overwrite
  existing library resources.
- Phase 105 supports animated GIF, WebP and PNG through ImageDecoder and local
  Lottie JSON through lottie-web 5.13.0. Random-access frames retain alpha and
  source timing in the shared reader used by preview/export. Lottie props and
  originals stay intact. External assets, fonts, expressions and compressed
  .lottie archives have explicit unsupported results. Unknown native graphic
  engines still retain their props and report the existing graphic warning.

## Runtime evidence

The licensed fixture is a 600 × 450 photograph of a person holding a microphone.
Its source, author and CC BY 2.0 licence are recorded in
`tests/fixtures/cutout/README.md`. The declared smoke-test quality threshold is at
least 1,000 foreground pixels above alpha 200 and 1,000 background pixels below
alpha 20, working manual repairs and preview/export RGB mean absolute error below 15. This is a fixture acceptance criterion, not a general model-accuracy claim.

- The fixture produced 108,455 foreground and 149,790 background pixels at those
  thresholds. A selected 60 × 60 face patch and a 60 × 50 jacket patch had mean
  alpha 1.0; a 100 × 60 background patch had mean alpha 0.0067. The selected
  microphone patch had mean alpha 0.49 before manual repair. See
  [unrepaired cutout](phases-101-105-cutout.png). The model can retain audience
  fragments, and accessory edges need manual repair.
- Forced include and exclude regions produced alpha 255 and 0. Encoding and
  decoding the exported transparent PNG preserved those exact repaired alphas.
  The job rejected an already-aborted signal and missing timestamp coverage.
- A generated one-second person video produced five mattes at 0.0, 0.2, 0.4, 0.6
  and 0.8 seconds. The initial run, including worker startup with the cached model,
  took 1.67 seconds, about 3 fps. Repeated runs in the JSON use the completed cache.
- A repaired cutout with crop, rotation and PiP placement over blue exported to
  WebM. Decoding it gave RGB mean absolute error 1.0583 against the preview.
  See [preview](phases-101-105-cutout-preview.png) and
  [decoded export](phases-101-105-cutout-export.png).
- SVG became an 866-byte PNG. Catalogue reopen preserved the original, companion
  licence and credit line; project storage reopen preserved the embedded credit.
  Search combined text, kind and licence filters. The identity LUT validated and
  Anton registered with its licence companion. Unsafe SVG and unsupported image
  input were rejected.
- A one-second Lottie square moved across transparent pixels. Seeking 0, 0.5,
  0.99 and back to 0 restored the expected positions and exact source alpha.
  The 849-byte WebM decoded at 0.5 seconds to `[255, 1, 0, 255]` on the square
  and `[1, 0, 255, 255]` on its blue background.
- Two-frame GIF, animated WebP and APNG fixtures preserved 0.5-second frame
  durations, moved their square, cleared the previous position and restored the
  first frame after seeking backward.

The compiled editor imported and placed the licensed photograph, enabled cutout,
ran the bundled model worker, added an exclude ellipse, downloaded a cutout PNG,
and restored the settings and cached matte after reload. There were no field

## Limits

Windows Chromium is the only verified target. Other browsers/platforms, public
hosting and macOS Tandem round trips remain unverified. The CPU worker requires
WebAssembly SIMD and OffscreenCanvas. MediaPipe accessory segmentation differs
from native RVM/Vision; no temporal smoothing or moving-person quality benchmark
is claimed. The video fixture repeats the same photograph. Sources are limited
to 60 seconds, 3,600 frames, 512 MiB input and 64 MiB compressed matte data.
Animated-image cutout analysis is rejected; use a video source instead.

Alpha export is a transparent PNG source frame up to 1280 px wide. The existing
WebM export remains opaque and composites cutouts and stickers over the timeline.
Transparent video export and native pixel-for-pixel matte/feather parity remain
outside this browser baseline. Choke uses separable square morphology and Canvas
blur, so its edge kernel differs from Core Image.

The library is local to this browser origin. Project JSON preserves provenance
and resource references, without embedding library binaries. Clearing browser
storage removes those local files. Credits reports, starter installation and
provider/network adapters remain assigned to phases 106–108. Local normalization
supports the kinds listed in its import picker; use ordinary Project media for
audio and video. Lottie supports self-contained shape/solid animations; complex
engine-specific effects have no native-renderer parity guarantee.
